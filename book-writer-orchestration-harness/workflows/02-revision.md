# 02-revision.md
목표: 리뷰어들의 주석 피드백을 초고에 반영
입력: chapter-{id}-draft.md, fact-notes.md, tech-notes.md, structure-notes.md, copy-notes.md
규칙
1. 각 피드백마다 반영 여부를 기록, 반영 불가 시 사유를 주석으로 남긴다
2. 수정 후에도 source 메타 주석은 유지한다
3. 코드 수정 시 실행 테스트를 고려하고 변경점을 표기
출력: chapter-{id}-revised.md
완료 조건: 모든 피드백에 대한 처리 기록 존재
